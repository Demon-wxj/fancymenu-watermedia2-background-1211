Modifications: subset to menu labels, ASCII and limited punctuation; instantiate
weight 600; rename the modified font to Unexplored Menu Serif SemiBold. Produced
with FontTools by repair-20260926-menu-video/prepare_menu_font.py. This project
does not claim authorship of the original glyph designs.

Runtime resource: assets/bcc_sao/font/menu.json and menu.ttf; font ID bcc_sao:menu.
The font is used only when a text component explicitly selects this ID. No vanilla
font is overridden. Because these assets ship inside the addon, no optional
resource pack needs to be enabled. The standalone ZIP remains an optional format.
